# Orca v0.1.6-alpha

This alpha focuses on smoother playback, more reliable library updates, and clearer lyrics and player views.

## What's New

- Phantom Mode keeps music playing while Orca's main window is closed. Restore the window with `Ctrl + Shift + B`.
- Windows media controls are available alongside the existing playback controls.
- The queue and playback session can be restored after restarting Orca. Seeking within a track no longer restarts playback when the audio format supports in-place seeking.
- Library folders update as files are added or changed. Unavailable sources remain configured instead of disappearing from the library settings.
- Matching local `.lrc` files take priority. The metadata editor can fetch lyrics, and plain, untimed lyrics now display as static text rather than pretending to be synced.
- Genre cards, song selection, album and artist navigation, and full-player startup have been refined.

## Downloads

- `Orca_0.1.6-alpha_x64-setup.exe`: Windows x64 installer.
- `Orca_0.1.6-alpha_x64-portable.exe`: Runs without an installer, but still uses Orca's normal user data locations.

Orca is still in alpha. Performance and stability with libraries larger than 5,000 tracks have not been broadly tested; please report issues on GitHub.
