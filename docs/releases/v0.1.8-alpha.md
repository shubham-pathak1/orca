# Orca v0.1.8-alpha

This update focuses on library organization, player controls, lyrics, artwork matching, and a smoother upgrade from earlier native builds.

## What's new

- Add Liked Songs and bulk playlist editing, with easier song membership controls.
- Include or exclude individual music subfolders without removing the parent folder. Folder removal now asks for confirmation.
- Dock lyrics and the queue beside the library, and refine the full player, background choices, seekbar, and navigation.
- Add a custom font picker and show explicit badges when audio tags provide them.
- Apply ReplayGain from audio tags during playback, with a setting to control it.

## Fixes and improvements

- Improve online artist and album artwork matching, including collaborations and fallback sources. Automatic artwork matching remains experimental.
- Improve timed lyrics matching and refresh behavior while preserving lyrics already saved in the file.
- Preserve library scroll position when returning from a detail page, and prevent liking a song from reloading library artwork.
- Improve Windows media controls and the portable executable.

## Updating

Close Orca, including its tray or background mode, before updating. On first launch, v0.1.8-alpha moves an existing native library, playlists, artwork, and settings to a stable data folder. Later versions reuse that folder. Portable users can extract the new ZIP into a separate directory.

Orca is still in alpha and currently supports Windows x64. If you find a problem, please [open an issue](https://github.com/shubham-pathak1/orca/issues) with your Orca version and steps to reproduce.
